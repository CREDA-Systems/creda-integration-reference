# Security Policy

## Purpose

CREDA Systems takes the security of publicly released integration materials seriously.

This repository currently contains architecture documentation, reference interfaces, examples, adapter guidance, and related public implementation materials.

Security reporting should be limited to issues affecting material actually published in this repository.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Where GitHub Private Vulnerability Reporting is enabled for this repository, use that mechanism.

If private vulnerability reporting is not available, use an official CREDA Systems contact channel.

When reporting a vulnerability, include:

* a clear description of the issue;
* the affected file, component, or version;
* steps to reproduce the issue where applicable;
* potential security impact;
* any known mitigations; and
* whether the issue has been disclosed elsewhere.

Please avoid including unnecessary sensitive, personal, confidential, or proprietary information.

## Supported Material

Security review applies to public material contained in this repository.

As implementation code is added, supported versions and affected components may be identified here.

## Out of Scope

The following are outside the scope of this repository security policy unless expressly incorporated into this repository:

* proprietary CREDA runtime services;
* internal CREDA Systems infrastructure;
* unpublished implementation methods;
* VTI Foundation Inc. systems, standards, or certification infrastructure;
* third-party blockchain or network infrastructure;
* third-party wallets, nodes, validators, APIs, or smart contracts;
* production credentials or secrets;
* social-engineering attacks;
* denial-of-service testing against systems not expressly authorized for testing; and
* attempts to obtain confidential or unpublished CREDA Systems material.

Security reports should not be used to request disclosure of proprietary methods, internal architecture, unpublished technical details, or other protected intellectual property.

## Coordinated Disclosure

CREDA Systems may request reasonable time to investigate and address a reported issue before public disclosure.

Submitting a report does not authorize access to systems, data, accounts, infrastructure, or services beyond what the reporter is otherwise permitted to access.

## Security and Governance Outcomes

Discovery or remediation of a security issue in this repository does not establish, modify, or determine:

* a CREDA® governance outcome;
* VTI Foundation Inc. conformance;
* certification status; or
* the validity of any separately maintained production implementation.

See `NOTICE.md` for additional intellectual-property and platform-boundary information.
